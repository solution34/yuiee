| 阶段 | 工作内容 | 可审查产物 | 退出条件 |
|---|---|---|---|

| C. AI 对话 | 截图粘贴、API Key 存储、图片请求、流式回复、结构化提取、多轮草稿 | 对话界面、适配器、模拟 API 测试 | 断流与 API 失败不污染日历；他人事项不自动纳入。 |
| D. 日历与模拟 | 周/日视图、模拟方案、澄清与修改、最终确认、编辑删除 | 可运行闭环、端到端测试 | 用户可完成截图到日历的完整路径。 |

| F. 发布 | 安全检查、回归测试、安装包、README、已知限制 | 第一版安装包与发布记录 | 所有 P0/P1 缺陷关闭，需求验收矩阵通过。 |

## 2. 需求追踪矩阵

| 需求 | 设计模块 | 核心验证 |
|---|---|---|
| FR-01、FR-02 | 对话 UI、粘贴输入 | 截图预览、移除、纯文字与图文发送。 |
| FR-03 | AI 适配器、流式事件桥 | 增量显示、断流重试与草稿保留。 |
| FR-04、FR-05 | 结构化提取与校验 | 多事项、他人事项、归属不明、缺少截止时刻。 |
| FR-06、FR-07 | 草稿状态机、模拟调度器 | 预览不写库；修改后旧版本不能确认。 |
| FR-08 | 确认服务、SQLite 事务 | 双击确认、重试、并发日程变化。 |
| FR-09 | 日/周日历、事项服务 | 查看、编辑、删除和重启保留。 |
| FR-10 | 提醒服务、Windows 通知 | 1 天/1 小时提醒、编辑取消、重启和错过提醒。 |
| FR-11、FR-12 | 登录启动、托盘、悬浮窗 | 打包版登录启动、拖动、隐藏与退出。 |
| FR-13 | 事项分类和确认服务 | 普通事项未确认前无提醒。 |
| FR-14 | Key 存储与设置 | 未配置、更新、屏蔽回显、日志检查。 |
| FR-15 | 统一错误状态、冲突处理 | 网络故障、无空位、时间含糊均不误写。 |

## 3. 工程约定

1. `main` 保持可构建；功能分支以 `codex/` 为前缀。小步提交，每次提交应说明对应需求 ID。
2. TypeScript 严格模式；共享输入输出类型与运行时校验并存，避免仅靠编译期类型信任模型或 IPC 数据。
3. 数据库迁移只向前运行，修改数据前先备份测试样本；为关键事务写回滚测试。
4. AI 适配器可注入假实现，自动测试不依赖真实 Key 或外部网络；仅发布前做一次授权的真实 API 端到端验证。
5. 代码检查、类型检查、自动化测试、构建纳入 CI；安装包和系统通知另在 Windows 人工验收。
6. 任何截图、Key、完整 API 请求不得进入 Git、测试快照或日志。

## 4. 第一版完成定义

- 需求矩阵 FR-01 至 FR-15 均有对应实现和验收证据。
- 从真实截图粘贴到最终确认、日历显示、到期提醒的主流程可重复完成。
- 不明确的事项不被自动保存；他人的事项不产生提醒；无空位不强行安排。
- 应用关闭主窗口后提醒仍可运行；用户显式退出和关闭开机启动的行为一致。
- 安装包能在目标 Windows 环境安装、启动、卸载；数据位置与删除方法写入 README。
- 交付测试结果、已知限制和后续版本候选事项。
